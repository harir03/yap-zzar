# Demo video checklist

Record ~2–3 minutes covering:

1. **Dashboard open** — dark UI with Checkout, Simulator, Buy Scout, WhatsApp, Wallets, Audit.
2. **Buy Scout** — enter product + needs → Run → show ranked picks + YouTube links.
3. **WhatsApp QR** — refresh panel; note linked / QR state.
4. **WhatsApp buy** — message \`buy wireless earbuds needs: under 3k\` → scout reply → \`buy confirm 1\` (no auto-pay).
5. **Checkout** — Razorpay test pay ₹250 → HMAC verified success banner.
6. **Gate** — Simulator: approve one offer, block injection / RFM / drain.
7. **Audit feed** — live decisions scrolling.
8. **Close** — “Research only; human confirm; every rupee gated.”

Tips: use test keys only; blur real phone numbers; keep OpenWA running for QR.
